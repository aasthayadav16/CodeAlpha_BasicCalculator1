# Basic Calculator in C

## About the Project
This project is a basic calculator developed using C programming as part of the CodeAlpha Internship.

It performs basic arithmetic operations based on user input.

## Features
- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used
- C Programming
- GCC Compiler

## Concepts Used
- Variables
- Conditional Statements
- Switch-Case
- User Input and Output
- Arithmetic Operators

## How to Run
1. Download the repository.
2. Open the project folder in a terminal.
3. Compile the program:

   `gcc calculator.c -o calculator`

4. Run the program:

   `./calculator`
